# DBOS-Resource-Management-Platform
DBOS-Based Resource Management Platform with EV Charging as a Real-World Workload
•The proposed project presents a DBOS-Based Resource Management Platform that combines
Operating System resource management concepts with Database Management System capabilities.
• The platform uses a database as a central source of system state and resource information.
• EV charging is selected as a real-world workload because charging stations contain limited resources
such as charging points, power capacity, and charging time.
• Multiple users may request charging resources simultaneously, creating resource allocation, scheduling,
synchronization, and concurrency problems.
• The proposed system aims to manage these requests using database-backed resource allocation and
OS-inspired scheduling.
• The system will maintain information about users, charging stations, charging requests, reservations,
resource allocation, transactions, and system logs.
• The project demonstrates how OS and DBMS concepts can work together to create a reliable resource
management platform
